---
title: Usage analytics
description: Product analytics behavior in this fork.
icon: ChartColumn
---

This fork does not initialize product analytics, send usage events or daily snapshots,
or collect marketing email subscriptions. PostHog is not a runtime dependency.

Local diagnostic logs and provider usage/cost information remain available. Requests
made by a user-configured AI provider, connected app, plugin download or self-hosted
server are part of those features and are independent of product analytics.
